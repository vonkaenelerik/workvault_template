## Quick reference
| Key | Does |
|---|---|
| Cmd+Shift+D | Today's daily note |
| Cmd+Shift+M | New meeting note |
| Cmd+Shift+J | New project note |
| Cmd+Shift+F | Search |
| Cmd+O | Open a note by name |
| Cmd+P | Run any command by name |
