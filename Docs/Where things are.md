# Where things are

## Folders (left sidebar, file explorer)
| Folder | What's in it | Named |
|---|---|---|
| `Daily/` | One note per day | `2026-11-02` |
| `Meetings/` | One note per meeting you chose to write up | `2026-11-02 Budget sync` |
| `Projects/` | One note per project (optional) | `Vendor migration` |
| `Templates/` | Templates for the above. Don't write notes here. | |
| `Docs/` | This guide | |
| root | `Home`, `Tags`, and any note made with Cmd+N or by clicking a link to a note that doesn't exist | |

## Sidebars
- **Left:** file explorer, search, bookmarks. Toggle with the panel icon at the top left.
- **Right:** backlinks (which notes link to the open note), outgoing links, outline, tags. Toggle with the panel icon at the top right.
- **Tags list:** Cmd+P → **Tags: Show tags**.

## Inside a daily note
1. **← / →**: previous and next calendar day
2. **Notes**: free writing
3. **Today**: open todos you planned for today (scheduled `⏳` today or earlier)
4. **Due / overdue**: open todos due today or earlier
5. **Waiting on others**: open todos tagged `#waiting`
6. **Backlog**: every other open todo, grouped by folder and note
7. **Done today**: todos completed on this note's date

## Inside a meeting note
- **Properties** at the top: `date`, `attendees`, `project`, `tags`
- **Notes**, **Action items**, **Decisions**

## Inside a project note
- **Properties**: `description`, `status`, `tags`
- **Linked notes & meetings**: notes that link to this project, newest first
- **Open todos**: todos in this note, plus todos anywhere that mention the project
- **Log**

## Other notes at the root
- **Home**: short overview and hotkeys
- **Tags**: what each tag means, plus a table of every tag in use
