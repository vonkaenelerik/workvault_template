# Keybindings

## Set up for this vault
| Key | Command | Does |
|---|---|---|
| Cmd+Shift+D | Daily notes: Open today's daily note | Opens today's note, creating it if needed |
| Cmd+Shift+M | Templater: Create Meeting | Asks for a title, creates `Meetings/YYYY-MM-DD Title` |
| Cmd+Shift+J | Templater: Create Project | Asks for a name, creates `Projects/Name` |

## Obsidian built-ins you'll use
| Key | Does |
|---|---|
| Cmd+P | Command palette: run any command by typing its name |
| Cmd+O | Quick switcher: open a note by typing part of its name |
| Cmd+Shift+F | Search all notes |
| Cmd+N | New blank note (lands at the vault root) |
| Cmd+L | Toggle checkbox on the current line |
| Cmd+E | Switch between editing and reading view |
| Cmd+Click a link | Open it in a new tab |
| Cmd+T / Cmd+W | New tab / close tab |
| Cmd+Option+← / → | Go back / forward |
| Cmd+, | Settings |

## Useful commands without a key (use Cmd+P)
| Command | Does |
|---|---|
| Tasks: Create or edit task | Form with a date picker for due dates |
| Tags: Show tags | Tag list with counts in the sidebar |
| Templater: Replace templates in the active file | Fixes a note showing raw `undefined` code |
| Daily notes: Open previous / next daily note | Jumps between existing daily notes, skipping gaps |

## Change a key
Settings (Cmd+,) → Hotkeys → search for the command → click the `+` or the existing key and press the new one.
